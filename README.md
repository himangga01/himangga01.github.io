# DEV PACK · 정재훈 포트폴리오

압축을 푼 뒤 `JaeHoon_portfolio.html`을 브라우저로 열면 바로 볼 수 있습니다. 서버나 설치, 인터넷 연결이 필요 없습니다.
모든 경로가 상대 경로라 폴더를 어디로 옮겨도 동작합니다. 폴더 안의 구조만 그대로 유지해 주세요.

```
devpack-portfolio/
├── JaeHoon_portfolio.html  시작 파일 · 페이지 전체 (카드·캐릭터 SVG 포함)
├── README.md
└── assets/
    ├── css/style.css       디자인, 홀로그램, 반응형
    ├── js/app.js           카드 기울기, 포장 열기 연출, 상세 보기, 필터
    ├── js/data.js          상세 보기와 포장 열기에 쓰는 프로젝트 데이터
    └── fonts/              Paperlogy 글꼴 (Regular·Medium·SemiBold·Bold·ExtraBold, woff2)
```
